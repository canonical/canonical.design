{% call section_header("Circle of Friends") %}

The Circle of Friends (CoF) is the core symbol of the Canonical and Ubuntu brands. It is the smallest unit used to identify Canonical and can be used by both Canonical and the Ubuntu community across a wide range of assets.

The symbol represents connection, collaboration, and openness - all of which are representative of our open source ethos. Its form can be described as three people holding their arms out and forming a continuous circle.

{% call section_header("Usage across formats") %}

Our logo system can be used across a wide range of formats, both digital and physical. This requires each element – logo, symbol, and tag – to be used intentionally, based on context, scale, and purpose.

{% endcall %} {% call tiered_item("Digital products", is_first=true) %}
{{ block_image("34d02588-8_1. Digital products.png", "Two application side navigations: an expanded one with the full Landscape logo, and a collapsed one with only the tag") }}

The logo is used in user interfaces and product surfaces to provide clearer associations to specific Canonical products. The full logo should be used in prominent placements, such as landing screens or when the navigation is expanded, while the tag can be used in constrained or repetitive UI.

{% endcall %} {% call tiered_item("Communication and collateral") %}
{{ block_image("79ae1f77-8_2. Communication and collateral.png", "A datasheet with the Canonical logo at the top left of its first page and as a signature on its last page") }}

Cover pages and signatures should primarily use the logo, to establish clear authorship. It should not be repeated throughout content. The standalone tag should be used alongside headings in presentations and webpages.

{% endcall %} {% call tiered_item("Diagrams") %}
{{ block_image("92e18502-8_3. Diagrams.png", "A diagram with the MAAS logo in a box that connects to boxes labelled CLI and UI") }}

Product names should primarily appear as text within diagrams. In certain cases, logos or tags may be used to provide clearer context. You can make use of logos when presented alongside third-party logos, and the tag when sufficient Canonical or product context is already established within the same space.

{% endcall %} {% call tiered_item("Illustrations") %}
{{ block_image("942d5cf6-8_4. Illustrations.png", "An isometric illustration of a circuit board, with the Circle of Friends symbol drawn in perspective on its chip") }}

Logos, tags, and symbols may be incorporated into illustrated compositions only when they provide meaningful and indispensable context. All elements must align with the illustration’s perspective, whether flat or isometric.

{% endcall %} {% call tiered_item("Physical event assets") %}
{{ block_image("a260fad7-8_5. Physical event assets.png", "An orange booth backdrop with the Canonical Ubuntu logo at the top left, and a counter with the tag used alone") }}

For physical event assets such as booth backdrops and banners, place the full logo in the top-left corner of the main surface. The “Canonical Ubuntu” logo wordmark was created especially for physical events, when a wide surface is available. The tag may be used alone in secondary placements, such as counters.

{% endcall %}
{% call section_header("Alignment") %}

Alongside our grid systems, we use different parts of the logo and the tag to align headlines, text, or other visual elements.

{% endcall %} {% call tiered_item("Vertical alignment options", is_first=true) %}
{{ block_image("61fa9b30-9_1. Vertical alignment options.png", "Two layouts with a headline and text below the Canonical logo: aligned to the left edge of the wordmark as the primary guide, and to the left edge of the tag as the alternative") }}

The Canonical logo structure can be used to establish a vertical alignment edge for surrounding content.

When space allows, the left edge of the wordmark should be used as the primary alignment reference. Headlines, images, and text align to this edge to create a clear and stable layout.

In more compact compositions, the left edge of the tag may instead be used as the alignment reference, allowing for a tighter structure while maintaining visual consistency.

{% endcall %} {% call tiered_item("Horizontal alignment") %}
{{ block_image("d1ad79be-9_2. Horizontal alignment.png", "Two layouts with content to the right of the Canonical logo: a headline and text on the baseline of the wordmark, and body text starting from its cap height") }}

Headlines align with the baseline of the wordmark and can align with its font size. If only the tag is used, the bottom of the symbol serves as the alignment guide. Text also follows on the same baseline for optimal horizontal alignment. When starting with body text without a heading, align from the cap height.

{% endcall %}
{% call section_header("Co-branding") %}

When companies decide to market products or showcase solutions together, we consider that a co-branding situation.

As a default, company-level logos should be locked up together. Ubuntu-specific announcements may allow for a Canonical Ubuntu logo to be locked up with another company’s logo, or in rare cases with a partner’s product logo.

Lockups should not be created for other Canonical product logos, and the Canonical logo should not be locked up with another company’s product logo.

{% endcall %} {% call tiered_item("Divider and general clear space", is_first=true) %}
{{ block_image("e00dc23e-10_1_1. Divider and general clear space-light.png", "The Canonical logo and a partner logo on a light background, separated by a vertical divider colored #A9A9A9, with clear space around each logo", attrs={"data-mode": "light"}) }} {{ block_image("63298201-10_1_2. Divider and general clear space-dark.png", "The Canonical logo and a partner logo on a dark background, separated by a vertical divider colored #4D4D4D, with clear space around each logo", attrs={"data-mode": "dark", "hidden": ""}) }}

Our clear space rules also apply to logo lockups. To create a lockup, Canonical places a centered vertical divider between logos, extending across the height of both logos. Use #A9A9A9 for the divider on light backgrounds and #4D4D4D on dark backgrounds. The divider should be 0.25 mm in print or 1 px on screen, with a height equal to the tag height plus x.

{% endcall %} {% call tiered_item("Alignment and sizes") %}
{{ block_image("5509d13d-10_2. Alignment and sizes.png", "Lockups of the Canonical logo with one and with two partner logos, aligned to the cap height and baseline of the Canonical wordmark") }}

Logos come in all shapes and sizes, and co-branded logo lockups should feel visually balanced. Use the wordmark cap height and baseline as a guide for horizontal alignment, but adjust scale and alignment to ensure equal optical weight for all logos. Keep all logos within divider height.

{% endcall %}
